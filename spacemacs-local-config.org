#+PROPERTY: header-args:emacs-lisp :mkdirp yes :results silent

* Instructions
Copy or symlink this file to =local-config.org= to customize your local machine configuration
with a comprehensive, mnemonic Spacemacs Evil keybinding architecture.
=local-config.org= is consumed by =README.org= and is not tracked by Git, allowing
host-specific layer selections, paths, and secrets.

Key architectural benefits of this Spacemacs configuration:
1. *True Modal & Mnemonic Design*: Follows the official Spacemacs conventions (~SPC~ global leader, ~,~ and ~SPC m~ major mode leader).
2. *Evil-First Integration*: Preserves Vim standards (~C-u~ for scroll, ~C-g~ for quick normal state return, ~s~ for evil-surround).
3. *Dual Major-Mode Access*: All major-mode bindings are registered concurrently to both ~,~ and ~SPC m~ for seamless muscle memory.
4. *Window & Buffer Ergonomics*: Integrates full Spacemacs window operations (~SPC w /~, ~SPC w -~, ~SPC w m~, ~SPC w u/U~), and alternate buffer toggling (~SPC TAB~).

* Key-bindings
** Architectural Principles & Evil Integration
1. *Dual Major-Mode Access (~SPC m~ and ~,~)*:
   - In Vim, ~,~ reverses character searches (~f~/~t~). In Spacemacs, ~,~ is the *major-mode local leader* (Section 9 of Spacemacs documentation).
   - In this configuration, all major-mode bindings are registered concurrently under both ~,~ and ~SPC m~ via =spacemacs/set-leader-keys-for-major-mode=.
2. *Evil-First Preservation*:
   - ~C-u~ remains dedicated to Evil scrolling up (=evil-want-C-u-scroll t=).
   - Universal argument is mapped to ~SPC u~.
   - Fast escape from =insert= state to =normal= state is provided via ~C-g~.
   - Visual surround operates on ~s~ via =evil-surround=.
3. *Window Ergonomics (=evil-window-map=)*:
   - Splits: ~SPC w /~ or ~SPC w v~ (vertical), ~SPC w -~ or ~SPC w s~ (horizontal).
   - Navigation: ~SPC w h/j/k/l~.
   - Manipulation: ~SPC w H/J/K/L~ (move window), ~SPC w d~ (delete window), ~SPC w m~ (maximize / delete others), ~SPC w =~ (balance).
   - Layout History: =winner-mode= enabled for ~SPC w u~ (undo) and ~SPC w U~ (redo).
4. *Buffer & File Ergonomics*:
   - ~SPC TAB~ toggles between current and last active buffer (=spacemacs/alternate-buffer=).
   - ~SPC f y y~ / ~f y d~ / ~f y n~ copies full file path, directory, or file name.
   - ~SPC f e d~ opens this literate configuration, and ~SPC f e R~ tangles and reloads it.
