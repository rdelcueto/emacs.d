* Bootstrapping & Initial Setup from Scratch

When setting up this configuration on a fresh machine or after removing generated directories (=elpaca/=, =tree-sitter/=, =lisp/=), follow these steps to initialize the environment:

** Quick Start (Automated Script)
The script =emacs_setup.sh= streamlines setup, testing, and verification. Running it without arguments executes the entire setup and verification sequence while streaming progress and recording all diagnostic messages to =emacs_setup.log=:

#+begin_src bash
./emacs_setup.sh
#+end_src

Scoped parameters for focused debugging and feedback loops:
- =./emacs_setup.sh clean=    : Deletes all generated tangle artifacts (=early-init.el=, =init.el=, =lisp/=) and compilation cache (=eln-cache/=)
- =./emacs_setup.sh --tangle=  : Tangling only
- =./emacs_setup.sh --compile= : Byte-compile syntax & macro validation only
- =./emacs_setup.sh --smoke=   : Headless boot smoke test only
- =./emacs_setup.sh --queues=  : Elpaca package build verification only
- =./emacs_setup.sh --modules= : Active module evaluation only
- =./emacs_setup.sh --hooks=   : Startup hooks / after-init emulation only

Flags supported:
- =./emacs_setup.sh --copy= : Copies =template-local-config.org= instead of symlinking.
- =./emacs_setup.sh --nw=   : Completes setup and immediately launches Emacs in terminal mode.
- =./emacs_setup.sh --gui=  : Completes setup and immediately launches Emacs in graphical mode.

If any failure occurs during package downloading, compilation, or hook evaluation, the script halts with a non-zero exit code and logs complete failure diagnostics into =emacs_setup.log= for debugging.

** Manual Step-by-Step Setup

*** 1. Create or Link Local Configuration
Host-specific layer inclusions, personal identity, typography profiles, and machine overrides are managed in =local-config.org= (untracked by Git). Create it by either symlinking or copying the version-controlled template:

#+begin_src bash
# Option A: Symlink template (tracks template inclusions directly)
ln -s template-local-config.org local-config.org

# Option B: Copy template (custom machine-specific edits)
cp template-local-config.org local-config.org
#+end_src

*** 2. Tangle the Literate Configuration
Extract all source blocks from =README.org= (and any modular layers included via =local-config.org=) into the runnable Elisp files (=early-init.el=, =init.el=, and =lisp/*.el=):

#+begin_src bash
emacs --batch --quick \
  --eval "(require 'org)" \
  --eval "(require 'ox)" \
  --eval '(setq org-confirm-babel-evaluate nil)' \
  --eval "(setq org-babel-pre-tangle-hook (list #'org-export-expand-include-keyword (lambda () (set-buffer-modified-p nil))))" \
  --eval '(org-babel-tangle-file "README.org")'
#+end_src

*** 3. Headless Bootstrap & Startup Hook Emulation
Because Elpaca processes package queues asynchronously and hooks are registered to =after-init-hook=, run Emacs in batch mode with startup hook emulation to download, compile, and evaluate all packages and active modules headlessly before launching interactively:

#+begin_src bash
emacs --batch \
  --load early-init.el \
  --load init.el \
  --eval '(progn
            (run-hooks (quote after-init-hook))
            (elpaca-wait)
            (dolist (mod active-modules)
              (require mod nil t))
            (message "All packages and modules bootstrapped successfully in %s." (emacs-init-time)))'
#+end_src

Once this headless step completes, launch Emacs normally via =emacs= or =emacs -nw=.

* Early Init (=early-init.el=)
Loaded before the GUI displays and before package managers run. Strips visual bloat, optimizes GC, and silences native-compilation noise.

#+begin_src emacs-lisp :tangle early-init.el
    ;;; early-init.el --- Early Init File -*- lexical-binding: t; no-byte-compile: t -*-

  ;; Defer garbage collection during initialization for speed
  (setq gc-cons-threshold most-positive-fixnum
        gc-cons-percentage 0.6)

  ;; Restore sane GC thresholds after initialization completes
  (add-hook 'after-init-hook
            (lambda ()
              (setq gc-cons-threshold (* 32 1024 1024) ; 32MB runtime threshold
                    gc-cons-percentage 0.1)))

  ;; Disable package.el in favor of Elpaca
  (setq package-enable-at-startup nil)

  ;; Native compilation settings (Emacs 30+)
  (when (featurep 'native-compile)
    (setq native-comp-async-report-warnings-errors nil ; Completely silence async compilation warnings
          native-comp-jit-compilation t
          native-comp-async-jobs-number
          (max 1 (- (string-to-number (string-trim-right (shell-command-to-string "nproc"))) 1))))

  ;; Suppress native compilation log popups
  (setq warning-suppress-types '((native-compiler)
  			       (comp)))

  ;; Strip GUI bloat BEFORE frame creation (prevents initial window flashes)
  (push '(menu-bar-lines . 0) default-frame-alist)
  (push '(tool-bar-lines . 0) default-frame-alist)
  (push '(vertical-scroll-bars) default-frame-alist)

  (setq menu-bar-mode nil
        tool-bar-mode nil
        scroll-bar-mode nil
        ring-bell-function 'ignore
        pixel-scroll-precision-mode t)

  ;; Frame geometry & startup defaults
  (setq frame-resize-pixelwise t
        frame-inhibit-implied-resize t
        inhibit-splash-screen t
        inhibit-startup-screen t
        inhibit-startup-echo-area-message user-login-name
        inhibit-startup-buffer-menu t)

  (add-to-list 'default-frame-alist '(undecorated . t))
#+end_src

* Primary Init & Module Loader (=init.el=)
Bootstraps Elpaca, loads macro extensions synchronously, loads Core, and starts modules.

#+begin_src emacs-lisp :tangle init.el
    ;;; init.el --- Modular Init File -*- lexical-binding: t; no-byte-compile: t -*-

  ;; 1. Add lisp directory to load-path
  (add-to-list 'load-path (expand-file-name "lisp" user-emacs-directory))

  ;; 2. Bootstrap Elpaca
  (defvar elpaca-installer-version 0.12)
  (defvar elpaca-directory (expand-file-name "elpaca/" user-emacs-directory))
  (defvar elpaca-builds-directory (expand-file-name "builds/" elpaca-directory))
  (defvar elpaca-sources-directory (expand-file-name "sources/" elpaca-directory))
  (defvar elpaca-order '(elpaca :repo "https://github.com/progfolio/elpaca.git"
                                :ref nil :depth 1 :inherit ignore
                                :files (:defaults "elpaca-test.el" (:exclude "extensions"))
                                :build (:not elpaca-activate)))
  (let* ((repo  (expand-file-name "elpaca/" elpaca-sources-directory))
         (build (expand-file-name "elpaca/" elpaca-builds-directory))
         (order (cdr elpaca-order))
         (default-directory repo))
    (add-to-list 'load-path (if (file-exists-p build) build repo))
    (unless (file-exists-p repo)
      (make-directory repo t)
      (when (<= emacs-major-version 28) (require 'subr-x))
      (condition-case-unless-debug err
          (if-let* ((buffer (pop-to-buffer-same-window "*elpaca-bootstrap*"))
                    ((zerop (apply #'call-process `("git" nil ,buffer t "clone"
                                                    ,@(when-let* ((depth (plist-get order :depth)))
                                                        (list (format "--depth=%d" depth) "--no-single-branch"))
                                                    ,(plist-get order :repo) ,repo))))
                    ((zerop (call-process "git" nil buffer t "checkout"
                                          (or (plist-get order :ref) "--"))))
                    (emacs (concat invocation-directory invocation-name))
                    ((zerop (call-process emacs nil buffer nil "-Q" "-L" "." "--batch"
                                          "--eval" "(byte-recompile-directory \".\" 0 'force)")))
                    ((require 'elpaca))
                    ((elpaca-generate-autoloads "elpaca" repo)))
              (progn (message "%s" (buffer-string)) (kill-buffer buffer))
            (error "%s" (with-current-buffer buffer (buffer-string))))
        ((error) (warn "%s" err) (delete-directory repo 'recursive))))
    (unless (require 'elpaca-autoloads nil t)
      (require 'elpaca)
      (elpaca-generate-autoloads "elpaca" repo)
      (let ((load-source-file-function nil)) (load "./elpaca-autoloads"))))
  (add-hook 'after-init-hook #'elpaca-process-queues)
  (elpaca `(,@elpaca-order))

  ;; Enable use-package integration with Elpaca
  (elpaca elpaca-use-package
    (elpaca-use-package-mode)
    (setq elpaca-use-package-by-default t))
  (setq use-package-always-ensure t)
  (elpaca-wait)

  ;; ---------------------------------------------------------------------------
  ;; 3. CRITICAL SYNCHRONOUS BOOTSTRAPPING
  ;; Upgrade built-ins and load macro-defining packages before any modules load.
  ;; ---------------------------------------------------------------------------
  (elpaca (compat :wait t))
  (elpaca (transient :wait t))
  (elpaca (general :wait t))
  ;; Require general immediately so :general is registered in use-package-keywords
  (require 'general)

  ;; 4. Always Load the Lean Core
  (require 'core-base)
  (require 'core-keys)
  (require 'core-ui)
  (require 'mod-nav)
#+end_src

** Base Defaults (=lisp/core-base.el=)

  ;;; core-base.el --- Essential System Defaults -*- lexical-binding: t -*-

  (use-package emacs
    :ensure nil
    :init
    ;; UTF-8 Everywhere
    (set-charset-priority 'unicode)
    (setq locale-coding-system 'utf-8
          coding-system-for-read 'utf-8
          coding-system-for-write 'utf-8
          default-process-coding-system '(utf-8-unix . utf-8-unix))
    (set-terminal-coding-system 'utf-8)
    (set-keyboard-coding-system 'utf-8)
    (set-selection-coding-system 'utf-8)
    (prefer-coding-system 'utf-8)

    ;; Backups & Auto-Saves
    (defvar core-base-auto-save-dir (expand-file-name "~/auto-save/"))
    (defvar core-base-backup-dir    (expand-file-name "~/emacs-backups/"))
    (make-directory core-base-auto-save-dir t)
    (make-directory core-base-backup-dir t)

    (setq backup-by-copying t
          create-lockfiles nil
          delete-by-moving-to-trash t
          backup-directory-alist `((".*" . ,core-base-backup-dir))
          auto-save-file-name-transforms `((".*" ,core-base-auto-save-dir t)))

    ;; Long Filename Auto-Save MD5 Protection
    (defun core-base-hashed-auto-save-file-name (orig-fun &rest args)
      "Hash directory prefix if filename approaches filesystem limits."
      (let* ((save-name (apply orig-fun args))
             (dir (file-name-directory save-name))
             (file (file-name-nondirectory save-name)))
        (when (and save-name (> (length file) 150) buffer-file-name)
          (let* ((orig-dir (file-name-directory buffer-file-name))
                 (hash (secure-hash 'md5 orig-dir))
                 (base (file-name-nondirectory buffer-file-name))
                 (new-file (format "#%s-%s#" hash base)))
            (setq save-name (expand-file-name new-file dir))))
        (unless (file-directory-p dir)
          (make-directory dir t))
        save-name))
    (advice-add 'make-auto-save-file-name :around #'core-base-hashed-auto-save-file-name)

    ;; Operational Defaults
    (setq enable-recursive-minibuffers t
          sentence-end-double-space nil
          indent-tabs-mode nil)
    (defalias 'yes-or-no-p 'y-or-n-p)
    (global-set-key (kbd "<escape>") 'keyboard-escape-quit)

    ;; Visual Editing Aids
    (show-paren-mode 1)
    (global-visual-line-mode 1)
    (setq show-trailing-whitespace t)

    ;; Native Line Numbers
    ;; Enable line numbers only where relevant (programming, config, and text writing)
    (setq display-line-numbers-type t
  	display-line-numbers-width-start t
  	display-line-numbers-widen nil
  	display-line-numbers-width 4)

    (add-hook 'prog-mode-hook #'display-line-numbers-mode)
    (add-hook 'text-mode-hook #'display-line-numbers-mode)
    (add-hook 'conf-mode-hook #'display-line-numbers-mode)

    ;; Command completions filtering
    (setq read-extended-command-predicate #'command-completion-default-include-p))

  ;; Recent Files
  (use-package recentf
    :ensure nil
    :hook (after-init . recentf-mode)
    :custom
    (recentf-max-saved-items 128)
    (recentf-auto-cleanup 'never)
    :config
    (add-to-list 'recentf-exclude "^/\\(?:ssh\\|su\\|sudo\\)?x?:")
    (add-to-list 'recentf-exclude "/tmp/")
    (add-to-list 'recentf-exclude "~/.emacs.d/elpaca/"))

  (defun config-tangle-and-reload ()
    "Save, tangle README.org, load the changed files, and process Elpaca queues."
    (interactive)
    (let ((config-file (expand-file-name "README.org" user-emacs-directory)))
      (when (file-exists-p config-file)
        (require 'ox)
        (let ((org-babel-pre-tangle-hook (list #'org-export-expand-include-keyword
                                               (lambda () (set-buffer-modified-p nil)))))
          (with-current-buffer (find-file-noselect config-file)
            (save-buffer)
            (org-babel-tangle)))
        (message "Configuration tangled successfully."))

      ;; 2. Re-load primary init
      (load-file user-init-file)

      ;; 3. Force Elpaca to execute any queued packages immediately
      (when (fboundp 'elpaca-process-queues)
        (elpaca-process-queues))

      (message "Emacs configuration reloaded.")))

  (provide 'core-base)
#+end_src

** Daemon & Host UI (=lisp/core-ui.el=)
#+begin_src emacs-lisp :tangle lisp/core-ui.el
  ;;; core-ui.el --- Robust Frame, Daemon & Host UI -*- lexical-binding: t -*-

  ;; 1. Agnostic Host Profile Configuration & Hooks
  (defvar core-ui-host-profiles
    '((t . (:font-size 12.0
  		     :mono-font "monospace"
  		     :serif-font "serif"
  		     :symbol-font nil)))
    "Alist mapping hostnames to UI font specifications. Key `t' is the fallback.")

  (defvar core-ui-frame-hook nil
    "Hook run after configuring any frame. Receives FRAME as argument.")

  (defvar core-ui-graphic-frame-hook nil
    "Hook run after configuring a GUI frame. Receives FRAME as argument.")

  (defvar core-ui-terminal-frame-hook nil
    "Hook run after configuring a TTY frame. Receives FRAME as argument.")

  (defun core-ui-current-profile ()
    "Retrieve profile matching current machine hostname."
    (or (alist-get (system-name) core-ui-host-profiles nil nil #'string=)
        (alist-get t core-ui-host-profiles)))

  ;; 2. Declarative Frame Setup (Eliminates GUI frame flickering)
  (let* ((profile (core-ui-current-profile))
         (mono    (plist-get profile :mono-font))
         (size    (plist-get profile :font-size)))
    (when (and mono size)
      (add-to-list 'default-frame-alist `(font . ,(format "%s-%s" mono size)))))

  ;; 3. Per-Frame Dispatcher (Handles emacsclient -c and -t safely)
  (defun core-ui-configure-graphic-frame (frame)
    "Configure GUI faces, proportional fonts, and symbols for FRAME."
    (with-selected-frame frame
      (let* ((profile (core-ui-current-profile))
             (serif   (plist-get profile :serif-font))
             (symbol  (plist-get profile :symbol-font))
             (size    (plist-get profile :font-size)))

        (when (and serif (find-font (font-spec :family serif)))
          (set-face-attribute 'variable-pitch frame
                              :font (font-spec :family serif :size size :weight 'medium)))

        (when (and symbol (find-font (font-spec :name symbol)))
          (set-fontset-font t 'symbol symbol frame 'append)
          (set-fontset-font t 'unicode symbol frame 'append)))
      (run-hook-with-args 'core-ui-graphic-frame-hook frame)))

  (defun core-ui-configure-terminal-frame (frame)
    "Configure TTY-specific overrides for FRAME."
    (run-hook-with-args 'core-ui-terminal-frame-hook frame))

  (defun core-ui-frame-dispatcher (frame)
    "Dispatch setup based on whether FRAME is graphical or terminal."
    (if (display-graphic-p frame)
        (core-ui-configure-graphic-frame frame)
      (core-ui-configure-terminal-frame frame))
    (run-hook-with-args 'core-ui-frame-hook frame))

  (add-hook 'after-make-frame-functions #'core-ui-frame-dispatcher)

  (unless (daemonp)
    (add-hook 'window-setup-hook
              (lambda () (core-ui-frame-dispatcher (selected-frame)))))

  ;; 4. Modus Themes (Works natively across GUI and TTY)
  (use-package modus-themes
    :ensure t
    :demand t
    :init
    (setq modus-themes-mixed-fonts t
          modus-themes-variable-pitch-ui t
          modus-themes-italic-constructs t
          modus-themes-bold-constructs t
          modus-themes-to-toggle '(modus-operandi modus-vivendi-tinted)
          modus-themes-headings
          '((agenda-structure . (variable-pitch light 2.0))
            (agenda-date . (variable-pitch regular 1.2))
            (t . (regular 1.15))))
    :config
    (modus-themes-load-theme 'modus-vivendi-tinted))

  (provide 'core-ui)
#+end_src

* Local Machine & Modular Layers (=local-config.org=)

Modular layers (version control, tree-sitter, LSP, completion, citre, languages,
PKM/org, notes, terminals, dired, readers, and AI) are defined in standalone Org
files within =layers/=.

Host-specific layer selections and local machine settings are managed via
=local-config.org=, which is consumed below. If setting up a new environment,
copy =template-local-config.org= to =local-config.org=.
